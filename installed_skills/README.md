# Installed agent skills

ZIP-installed skill workspaces (each folder contains `SKILL.md`).

State: `installed.json` (gitignored). Install via panel **Agent → Skills** or `POST /gateway/skills/install`.

Example layout:

```
installed_skills/
  my-skill/
    SKILL.md
```

See `skills/README.md` and `config/skill_manifest.example.json`.
