# Scrape workflow

Submit URLs, monitor batches, and browse the product catalog.

## 1. Submit a batch

**Workflow → Batch queue** — paste URLs from 1688, Taobao, AliExpress, or enabled source plugins.

## 2. Monitor progress

Running batches show on the dashboard and batch detail pages. Cancel from the batch view if needed.

## 3. Catalog and files

- **Artifact → Products** lists saved items.
- **Artifact → Files** shows export output on disk.

## 4. Optional AI extraction

Per-job `use_ai` overrides engine defaults. Gateway agent tools can also scrape with `use_ai` when calling `scrape_product`.
