# 1688 source plugin

Built-in scrape plugin for 1688 product pages.

## Enable

1. Open **App Store** → find **1688**
2. Click **Enable** (source plugins register in `config/plugins.yaml`)
3. Confirm status shows **running** in the plugin drawer

## Requirements

- Valid session cookies for 1688 when pages require login
- Browser-capable scrape engine for anti-bot pages (see capabilities in the spec tab)

## Data model

Exports normalize to the shared `ScrapedProduct` shape with CNY as the default currency. Standard fields include title, price, images, SKU variants, and supplier hints.

## Agent usage

Enable **scrape-assistant** so the gateway agent can call `scrape_product` against 1688 URLs the operator provides.
