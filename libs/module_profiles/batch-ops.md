# Batch ops

Use for bulk URL ingestion — complements **scrape-assistant** (single URL).

## Tools

- `submit_batch` — queue many URLs
- `list_products` / `runtime_status` — verify outcomes

Enable alongside scrape-assistant when operators routinely paste URL lists in chat.
