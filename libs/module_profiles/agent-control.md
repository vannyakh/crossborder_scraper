# Agent control

Skill for operators who manage the gateway from Agent chat or Telegram.

## Tools

Includes schedule CRUD, integrate channel listing, and `runtime_status` for live checks.

## When to enable

Enable when operators should ask the agent to create cron tasks, reload integrate channels, or inspect gateway health without opening the panel.
