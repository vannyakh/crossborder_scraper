# PostgreSQL

Managed PostgreSQL via Docker or native apt install on Linux VPS hosts.

## Defaults

- Port `5432`, database `panel`, user `panel`
- Credentials generated on install — open the plugin drawer to copy them

## Database tools

After install, use **Databases → PostgreSQL** for table browse, SQL console, and schema actions.
